# NotariOS-ის გაშვების პირობები

სტატიკური გვერდი ნოტარიუსისა და ქართველი იურისტებისთვის: რა პირობებით შეუძლია ნოტარიუსს NotariOS-ში რეალური საქმის დაწყება, რა უნდა იყოს მანამდე შესრულებული და რატომ არის ეს დასაშვები. სამუშაო ვერსიაა განსახილველად და იურიდიული დასკვნა არ არის.

გვერდი ქვეყნდება GitHub Pages-ით, main შტოს ძირეული საქაღალდიდან: `index.html` და `assets/styles.css`.

რეპოზიტორია საჯაროა, ამიტომ მასში არაფერი უნდა მოხვდეს, რაც კონკრეტულ ნოტარიუსს, მის ბიუროს ან კლიენტს ამოსაცნობს ხდის.

ინგლისური პირველწყარო დოკუმენტები (შენახვის ვადების განრიგი, დამუშავების აღრიცხვა, კონფიდენციალურობის შეტყობინება, ხელშეკრულება დამუშავებაზე უფლებამოსილ პირთან) NotariOS-ის რეპოზიტორიაშია, `docs/data-protection/` საქაღალდეში.
